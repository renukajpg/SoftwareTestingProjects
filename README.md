# Manual Testing Project

This repository provides a complete manual testing framework for a sample web/mobile application. It includes:

- ✅ A detailed **Test Plan**
- 🧪 Well-structured **Test Scenarios & Test Cases**
- 📄 Supporting documentation for test execution and reporting

## 📌 Objective

To demonstrate a systematic approach to manual testing, covering:
- Requirement analysis
- Test planning
- Test design
- Test execution
- Defect reporting

### 1. **Test Plan**
- Test Objectives
- Scope (In & Out)
- Testing Types (Functional, Regression, UI, etc.)
- Test Deliverables
- Entry & Exit Criteria
- Schedule and Milestones

### 2. **Test Cases**
- Based on real-world scenarios
- Includes: Test Case ID, Description, Pre-conditions, Steps, Expected Result, Actual Result, Status
- Covers different modules and testing techniques

### 3. **Bug Reports**
- Bug report template with fields such as severity, priority, steps to reproduce, screenshots, etc.

## 🔧 Tools Used
- Excel (for test cases)
- Word/PDF (for documentation)
- Postman (for API testing, if applicable)
- Browser Developer Tools (for UI checks)
